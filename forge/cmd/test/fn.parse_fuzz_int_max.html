Parses the fuzz-int-max value from string to U256. Supports:

  • Decimal: “340282366920938463463374607431768211455”
  • Hex: “0xFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFFF”
  • Keywords: “u128”, “u128_max”, “u64”, “u64_max”
